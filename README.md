# Fun Student

Приложение для управления студентами и пользователями.

### Технологии
- Java 21, Spring Boot
- PostgreSQL
- Spring Security, JWT
- HTML, CSS, JavaScript
- JUnit 5, Mockito

### Запуск
Требуется Java 21 и PostgreSQL.

```bash
./run-local.sh
```

Приложение доступно по адресу: http://localhost:8080

### Тестирование
```bash
./mvnw test
```
